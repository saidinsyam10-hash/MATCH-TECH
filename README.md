# Match-Tech: Cocokkan Masalah & Solusi
### Game Edukasi Interaktif Kelas Teknologi Terapan — Madrasah Aliyah (MAN 1 MAJENE)

Aplikasi web edukatif interaktif bertema Madrasah untuk kegiatan *ice-breaking* dan pembelajaran berpikir kritis pada mata pelajaran **Teknologi Terapan**.

---

## 🌟 Fitur Utama

1. **Desain Terang Bernuansa Madrasah:**
   - Nuansa warna hijau zamrud Kementerian Agama / Madrasah (`#047857`) dan aksen emas (`#d97706`).
   - Ilustrasi karakter avatar Madrasah Aliyah:
     - **Aisyah:** Siswi berhijab putih rapi dan seragam hijau madrasah.
     - **Faris:** Siswa berseragam hijau madrasah dan berpeci/songkok hitam.

2. **Sistem Login Kelompok:**
   - Form identitas kelompok di halaman utama dengan tombol pintas cepat `[Kelompok 1]` s/d `[Kelompok 6]`.
   - Nama kelompok yang sedang bertanding ditampilkan secara langsung di layar proyektor kelas.

3. **Babak 1: Match-Tech (1 Menit):**
   - Siswa memasangkan 5 masalah nyata sosial/lingkungan dengan solusi teknologi terapan yang tepat.
   - Pilihan dievaluasi serempak di akhir 1 menit.

4. **Babak 2: Aksi Pungut Sampah Sekolah (30 Detik):**
   - Mini-game interaktif di halaman sekolah madrasah.
   - Siswa memungut sampah plastik sebanyak-banyaknya dalam 30 detik untuk mendulang poin tambahan.

5. **Papan Juara Pemenang (Leaderboard) & Suara Meriah:**
   - Menyimpan peringkat dan skor seluruh kelompok di kelas.
   - Suara *triumphant fanfare* (terompet kemenangan) dan hujan konfeti saat papan juara dibuka.
   - Fitur salin rekap nilai untuk catatan guru.

---

## 🚀 Menjalankan Secara Lokal
Cukup buka file `index.html` langsung di browser (Google Chrome, Microsoft Edge, Firefox, dll.), atau jalankan server lokal:
```bash
npx serve .
```
